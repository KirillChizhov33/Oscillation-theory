# Oscillation-theory

## Description
The repository contains MatLab, Python, etc scripts to simplify the study of mathematical models such as Newton's method for finding fixed points, numerical calculation of integrals, etc.

## Installation
1. git clone https://github.com/KirillChizhov33/Oscillation-theory.git
2. Go to "dev" branch or create the new one
3. git add -u
4. git commit -m "Your changes description"
5. git push
